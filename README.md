# CrabCrust

CrabCrust is a Rust toolkit for drawing arcade-style animations in the terminal and wrapping real commands with them. Graphics are Unicode braille: each cell is a 2×4 dot grid. A wrapper runs the underlying program, keeps its stdout, stderr, and exit code, and plays a procedural animation for that outcome.

## Text captures

These frames are braille, so they render in a normal terminal without a tty takeover. Regenerate them with:

```bash
cargo run --example text_frames
```

## Library

Render a frame with no terminal:

```rust
use std::time::Duration;
use crabcrust::{Animation, BrailleGrid, SpinnerAnimation};

let mut spinner = SpinnerAnimation::new();
spinner.update(Duration::from_millis(200));
let mut grid = BrailleGrid::new(24, 10);
spinner.render(&mut grid);
println!("{}", grid.to_trimmed_text());
```

Run a program and keep the real result:

```rust
use crabcrust::CommandExecutor;

let result = CommandExecutor::new("git", &["status"])
    .run()
    .expect("git status");
println!("{}", result.combined_output());
std::process::exit(result.exit_code);
```

`AnimationPlayer` plays the same animations inline or fullscreen. `GitWrapper` maps `commit`, `push`, `pull`, `merge`, and `status` onto themed animations.

## Animations

| Animation | Typical command | What the frame shows |
| --- | --- | --- |
| Spinner | any in-progress command | rotating trail |
| Save | `git commit` | floppy disk, progress bar, checkmark |
| Rocket | `git push` | rocket and starfield |
| Download | `git pull` | downward arrow and falling marks |
| Merge | `git merge` | two branches joining |
| Rabbit | `git pull` | hopping rabbit with a clock |
| Fireworks, confetti, trophy, baby | successful commit or push | celebration |
| Matrix rain | `git status` | falling glyphs that decode the output |

## Getting started

```bash
git clone https://github.com/newjordan/CrabCrust.git
cd CrabCrust
cargo build --release
cargo run -- demo all
```

Wrap git:

```bash
cargo run -- git commit -m "Prototype CLI feedback"
cargo run -- git push
```

Optional shell alias:

```bash
alias git="crabcrust git"
```

Headless examples:

```bash
cargo run --example text_frames
cargo run --example wrap_command
```

GIF conversion is behind the `gif` feature. Video files also need the `video` feature and a system FFmpeg install.

## Tests

```bash
cargo test
cargo test --features gif
```

Frame snapshots live in `tests/snapshots/`. GitHub Actions runs rustfmt, Clippy, and those tests on every pull request.
